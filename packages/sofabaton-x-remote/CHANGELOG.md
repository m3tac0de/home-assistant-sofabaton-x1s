# Changelog

## Unreleased

## 0.1.4 (2026-10-28)

Changes since `sofabaton-x-remote-v0.1.3`.

- Update the shared Virtual Remote to 0.2.9. The shared state reads the
  hub's activity and device icon and X2 color, and the bundled icon set
  gains the few icons the Home Assistant sidebar uses for them; the
  embedded remote's interface is unchanged.
- The element's attributes, methods and events are unchanged. The minimum
  server version remains 0.2.2; server 0.2.7 ships the corresponding
  server-hosted bundle.

## 0.1.3 (2026-10-17)

Changes since `sofabaton-x-remote-v0.1.2`.

- Update the shared Virtual Remote bundle to 0.2.8. This includes updated
  shared translation data for the Home Assistant sidebar; those text
  changes do not affect the embedded remote's interface.
- The element's attributes, methods and events are unchanged. The minimum
  server version remains 0.2.2; server 0.2.6 ships the corresponding
  server-hosted bundle.

## 0.1.2 (2026-10-09)

Changes since `sofabaton-x-remote-v0.1.1`.

- Update the shared Virtual Remote to 0.2.7: improved theme contrast and
  dropdown readability, corrected EXIT-button behavior, and device-keymap
  loading and retry fixes.
- Include current translations and shared remote layout fixes.
- The element's attributes, methods and events are unchanged. The minimum
  server version remains 0.2.2; server 0.2.5 ships the corresponding
  server-hosted bundle.
